# Demonstration Script

## Demo Duration

Recommended duration: 8 to 10 minutes.

## Flow

1. Open the dashboard.
2. Show three online workshop nodes.
3. Show CPU, memory, disk, network, and production status.
4. Inject a common fault, such as high disk usage.
5. Show local script repair and audit log.
6. Inject a complex fault, such as high CPU plus API latency.
7. Show DeepSeek diagnosis result.
8. Inject hostile traffic to one workshop node.
9. Show node isolation and central system stability.
10. Trigger market demand change.
11. Show production plan adjustment.
12. Switch users to demonstrate permission differences.
13. Generate a factory production report.

## Key Message

The system demonstrates not only monitoring, but also the full loop of
detection, diagnosis, action, isolation, audit, and production optimization.
