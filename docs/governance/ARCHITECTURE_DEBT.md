## Debt Policy

- A temporary solution remains only while its risk, owner, phase and executable exit condition are visible.
- Adding behavior to `MemoryStore`, a shadow table or a shared-token route requires an update here and in the source-of-truth matrix.
- `Works in demo`, HTTP 200, SimPy output or a page rendering does not close industrial debt.
- A P0/P1 item that blocks the current phase is handled before later features.
- Closed items can reopen when their evidence no longer runs or a new scope invalidates the control.
